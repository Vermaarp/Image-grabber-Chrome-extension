# Image Grabber

A lightweight and easy-to-use Chrome extension that allows users to instantly extract and download images from any webpage. Whether you're collecting inspiration, saving assets, or analyzing page content, Image Grabber simplifies the process with a clean interface and fast performance.

---

## 🚀 Features

- 🔍 Automatically detects all images on a webpage  
- 🖼️ Preview images before downloading  
- ⬇️ One-click download for individual or multiple images  
- 🎯 Filter images by size, type, or source  
- ⚡ Fast and minimal performance impact  
- 🧩 Simple and intuitive UI  

---

## 💡 Use Cases

- Designers gathering visual inspiration  
- Developers analyzing web assets  
- Researchers collecting image data  
- Everyday users saving images effortlessly  

---

## 🛠️ Tech Stack

- JavaScript  
- HTML/CSS  
- Chrome Extensions API  

---

## 📦 Installation

1. Clone this repository  
2. Open Chrome and navigate to `chrome://extensions/`  
3. Enable **Developer Mode**  
4. Click **Load unpacked** and select the project folder
